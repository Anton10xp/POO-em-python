# Programação Orientada a Objetos (POO) - Python

Repositório com implementações práticas de Programação Orientada a Objetos (classes, herança, encapsulamento, polimorfismo) desenvolvidas em Python durante a disciplina de POO.

## 📋 Pré-requisitos

Para rodar os códigos deste repositório, você precisa ter instalado:

- **Python 3.x** (recomendado 3.8 ou superior)

Verifique se o Python está instalado digitando no terminal:
```bash
python --version
```
ou
```bash
python3 --version
```

Caso não tenha instalado, baixe em: https://www.python.org/downloads/

## 🚀 Como rodar

1. Clone este repositório:
```bash
git clone https://github.com/Anton10xp/POO-em-python.git
```

2. Entre na pasta do projeto:
```bash
cd POO-em-python
```

3. Execute o arquivo desejado:
```bash
python nome_do_arquivo.py
```

## 📁 Estrutura do repositório

Cada arquivo representa um exercício ou conceito estudado na disciplina de POO, como:
- Classes e objetos
- Herança
- Encapsulamento
- Polimorfismo
- Métodos especiais (dunder methods)
